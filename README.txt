Deployment

The website is connected to its GitHub repository and automatically deploys from the main branch.

To publish updates:

Make and save changes locally.
Commit the changes in Git.
Push the changes to the main branch on GitHub.
The hosting service will automatically build and deploy the updated website.

Example commands:

git add .
git commit -m "Describe the website update"
git push origin main

Always run Git commands from inside the project folder:

C:\Users\Cory Hanna\OneDrive\Desktop\VS Code\coryhanna.com
